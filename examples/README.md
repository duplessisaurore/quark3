# Examples

This directory contains a bunch of examples for the usage of the `collider3` toolchain including `Gluon3`, `Boson3` and `Quark3`.

You can compile them to `Lepton3` generally by running `collider3 <path/to/example/build.toml>`.

## core

The core example contains a bunch of macro definitions in a `std` library which replicate the style of other commonly used programming languages. This example serves as a good starting point for understanding the macro system of `Boson3`, and may serve as a useful start for other programming projects in `Boson3`.
